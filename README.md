## About TextBrew

TextBrew is the automated product description generator that simplifies your life and scales your e-commerce content operations. This repository houses the core backend service, queue management infrastructure, and the newly integrated **Poiza Hardware Order Monitoring System**.

---

## 🚀 Poiza Hardware Order Monitoring System

The Poiza integration tracks and syncs hardware orders seamlessly within the TextBrew backend infrastructure.

### 1. Environment Configuration
Ensure your `.env` file includes the correct API endpoints and database credentials for the Poiza hardware tracking service:
```env
POIZA_API_URL=https://api.poiza.hardware.com/v1
POIZA_WEBHOOK_SECRET=your_webhook_secret_here
```

### 2. Monitoring Commands
Use custom Artisan commands to manage, sync, and check the status of Poiza hardware orders:

* **Sync active hardware orders:**
  ```bash
  php artisan poiza:sync-orders
  ```

* **Check the real-time status of a specific order:**
  ```bash
  php artisan poiza:check-status {order_id}
  ```

* **Retry failed order processing jobs:**
  ```bash
  php artisan queue:retry --queue=poiza-hardware
  ```

### 3. Queue Configuration for Hardware Tracking
Poiza hardware order events utilize a dedicated queue channel to ensure timely updates. Configure your Supervisor process monitor in production:
```ini
[program:textbrew-poiza-worker]
process_name=%(program_name)s_%(process_num)01d
command=php /path/to/textbrew/artisan queue:work database --queue=poiza-hardware --sleep=3 --tries=3
autostart=true
autorestart=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/path/to/textbrew/storage/logs/poiza-worker.log
```

## ⚙️ Running Queues in Laravel

To run standard queues in Laravel for TextBrew:

1. Verify your queue connection in your `.env` file:
   ```env
   QUEUE_CONNECTION=database
   ```

2. Run database migrations to create the required jobs table:
   ```bash
   php artisan queue:table && php artisan migrate
   ```

3. Start the standard queue worker:
   ```bash
   php artisan queue:work
   ```
   > *Tip: For production, always use a process monitor like Supervisor to keep queue workers running reliably.*

4. Retry failed jobs using:
   ```bash
   php artisan queue:retry all
   ```

For more information on Laravel queues, refer to the [official Laravel documentation](https://laravel.com/docs/queues).
